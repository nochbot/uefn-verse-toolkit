# UEFN Verse Toolkit

A collection of reusable Verse systems, gameplay mechanics, UI helpers, and optimization patterns for Fortnite UEFN creators.

The goal of this project is to make common UEFN systems easier to understand, reuse, modify, and integrate into larger projects.

## Planned Systems

- Modular tycoon purchase/build system
- Animated prop spawning and building
- Prop show/hide utilities
- Player currency and progression
- Marketplace and purchase systems
- Superpower framework
- Reusable UI systems
- Player interaction systems
- Gameplay utilities
- Performance-conscious Verse patterns

## Structure

```text
├── ui/
├── utilities/
└── examples/
```

## Goals

This toolkit focuses on:

- Reusable systems instead of map-specific code
- Modular architecture
- Clear Verse code
- Easy configuration
- Performance-conscious implementations
- Examples that can be adapted to different UEFN projects

## Examples

Example projects and setup instructions will be added alongside each system.
